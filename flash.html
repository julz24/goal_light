Canadiens Goal Light

ESP32-C3 Super Mini — Flash via navigateur

  1. Brancher l'ESP32-C3 en USB
  2. Cliquer Install ci-dessus
  3. Sélectionner le port COM/ttyUSB
  4. Attendre la fin du flash (~30 sec)
  5. Connecter au réseau Wi-Fi CanadiensGoalLight
  6. Entrer tes identifiants Wi-Fi
  7. Ajouter l'intégration dans Home Assistant via HACS
